## Featured Papers

### [Automatic dual basis sets for self-consistent field calculations](https://arxiv.org/abs/2611.34694v1)
**Authors:** Joonatan Huhtasalo, Susi Lehtola
**Published:** 2026-11-25
**Summary:** Presents an automatic generator of pruned dual basis sets for SCF calculations, finding that current Fock matrix initial guesses are too inaccurate to enable adaptive basis sets.

**What's new**
- Automatically constructs pruned dual basis sets from a target orbital basis for a given precision threshold and Fock matrix.
- Larger basis sets retain a smaller fraction of basis functions, as expected.
- Generated dual basis sets show similar performance across systems from the first four periods.
- Current initial guesses for the Fock matrix are not accurate enough to unlock adaptive basis sets.
- Suggests the same limitation may apply to similar basis compactification attempts.

### [Frozen Phonons on Dense $\mathbf{q}$-Grids Using Set Covers](https://arxiv.org/abs/2611.34638v1)
**Authors:** Sebastian Riis Thomsen
**Published:** 2026-11-25
**Summary:** A set-cover method finds a minimal set of non-diagonal supercells covering all q-points on a dense grid, cutting frozen-phonon computational cost.

**What's new**
- Replaces one-supercell-per-q-point with a minimal set of supercells each commensurate with multiple q-points.
- Presents an algorithm with a proof of optimality and pseudocode.
- Discusses how the number of supercells scales with q-grid density.
- Numerical tests show large savings that grow with grid density.

### [LetzElPhC: an electron-phonon code for efficient exciton-phonon workflows](https://arxiv.org/abs/2611.34500v1)
**Authors:** Muralidhar Nalabothula, Ludger Wirtz
**Published:** 2026-11-25
**Summary:** LetzElPhC is an open-source code computing electron-phonon matrix elements from Quantum ESPRESSO DFPT output for scalable exciton-phonon workflows with Yambo.

**What's new**
- Computes electron-phonon matrix elements from Quantum ESPRESSO DFPT output.
- Interfaces directly with Yambo and exploits crystal symmetries for scalable exciton-phonon workflows.
- Enforces strict gauge consistency between Bloch states and Bethe-Salpeter excitonic wave functions.
- Uses Fourier interpolation of dynamical matrices and perturbed Kohn-Sham potentials with dipole/quadrupole corrections.
- Supports multi-level parallelization and efficient parallel I/O for dense momentum grids.

### [EGQCA Code: automated high-throughput thermodynamic modeling of solid solutions](https://arxiv.org/abs/2611.34551v1)
**Authors:** Dominik Spath, Luka Wibmer, Kieran Bozier, Ralf Meyer, Eva Kogler, Efisio Madeddu, Chris Pickard, Markus Aichhorn, Simone Di Cataldo, Luiz T. F. Eleno, Christoph Heil, Pedro N. Ferreira
**Published:** 2026-11-25
**Summary:** EGQCA code automates high-throughput thermodynamic modeling of solid solutions, using machine-learned potentials to cut cluster calculation costs by up to five orders of magnitude.

**What's new**
- Open code package implementing the extended generalized quasichemical approximation (EGQCA) for solid solutions
- Automates the full workflow and interfaces with DFT codes and universal machine-learned interatomic potentials

### [PineIR: 3D molecular structures from an infrared spectrum alone](https://arxiv.org/abs/2611.34334v1)
**Authors:** Giulio Benedini, Pierre-Paul De Breuck, Miguel A. L. Marques, Silvana Botti
**Published:** 2026-11-25
**Summary:** PineIR is a generative model that reconstructs 3D molecular structures from an infrared spectrum alone, without extra inputs like Raman, NMR, or molecular formula.

**What's new**
- First model to infer full 3D molecular structure from IR spectrum alone, no auxiliary data needed
- Builds molecules atom by atom, subtracting each atom's IR contribution before generating the next
- Trained on IR spectra of 4.6M structures from 3.1M molecules computed with a machine-learned potential
- Best of 50 candidates has correct connectivity in 43% of held-out cases
- Fine-tuned on 161k B3LYP spectra to extend applicability to hybrid-functional level

### [Tune for Retention, Not Just Gain: SFT Forgets Far Less than You Think](https://arxiv.org/abs/2611.34579v1)
**Authors:** Nirmit Joshi, Nathan Srebro, Eran Malach
**Published:** 2026-11-25
**Summary:** Vanilla SFT with lower learning rate and batch size retains prior capabilities far better than believed, rivaling on-policy SDFT when tuned for both gain and retention.

**What's new**
- Challenges the premise that off-policy SFT inherently causes catastrophic forgetting.
- Lower learning rate and batch size yield similar new-task gains with little to no forgetting.
- Jointly tuned vanilla SFT is competitive with Self-Distillation Fine-Tuning on retention.
- SDFT is more robust to hyperparameters but still needs a retention-aware criterion.
- Questions whether on-policy training is what enables learning with retention.

### [Any-Rate: Half-Bit Multi-Precision LLM Quantization with Coded Bit-Planes](https://arxiv.org/abs/2611.34402v1)
**Authors:** Hoonki Lee, Haechan Shin, Hyuntaek Jung, Yeonu Choi, Sangyeob Kim
**Published:** 2026-11-25
**Summary:** Any-Rate serves 2-8 bit LLM quantization from one checkpoint in half-bit steps over 2-4 bits using coded bit-planes, improving low-bit accuracy.

**What's new**
- Introduces half-bit precision steps (2-4 bits) from a single nested checkpoint, unlike prior integer-bit methods.
- Restricts some bit-planes to extended Hamming codewords in 8-weight blocks at 0.5 bits per weight.
- Shares one LUT per row across precisions and jointly encodes all precisions with separate targets.
- Achieves state-of-the-art multi-precision accuracy at 2 and 3 bits, retaining 69% of FP16 accuracy at 2 bits.
- Decodes about as fast as existing kernels, with up to 27% less LPDDR energy at equal accuracy.
