# Daily Issue (JST): 2026-10-29

## What's New Today

**AI agents learn to act, reason, and remember; materials simulation gets differentiable and quantum-corrected**

This digest spans a broad set of AI/ML advances—from test-time intervention control and prompt-injection defenses to world models and agentic RL—alongside materials and physics work on differentiable simulation, quantum-corrected thermodynamics, and magnetic crystal generation. A recurring theme is making learned systems more reliable and efficient: knowing when to intervene, how to allocate evaluation budgets, and how to ground reasoning in evidence. Several papers also probe the limits of current methods, including latent world models that fail to capture true dynamics and uncertainty quantification that breaks under class imbalance.

**Highlights**
- PORTAL learns when to deploy test-time adaptation interventions and which inputs to label, avoiding harmful updates.
- Heads of Security adds learned per-head attention gates to separate instructions from untrusted data, improving prompt-injection robustness.
- ThinkWorld grounds vision-language-action reasoning in world dynamics via Chain-of-Dynamics tokens and reinforcement learning.
- KPPax generates differentiable JAX code from KPP chemical mechanisms, enabling gradient-based ML in atmospheric chemistry.
- FixXPT brings quantum-corrected two/three-phase thermodynamics natively into LAMMPS for equilibrium trajectories.
- GMMag generates crystal structures with site-resolved magnetic moments using a conditional VAE and Gaussian-mixture retargeting.
- A theoretical study shows attention with per-entity frame freedom reduces to Wilson-loop edge updates, linking transformers to lattice gauge theory.

### [When Should We Intervene at Test Time?](https://arxiv.org/abs/2610.37658v1)
**Authors:** Jiahao Zhang, Xinling Wen, Liangliang Li, Yu Chen
**Published:** 2026-10-27
**Summary:** PORTAL is a controller that decides when to apply test-time interventions, which inputs to label, and when to stop querying, using shared label comparisons across candidate prediction rules.

**What's new**
- Frames test-time intervention as a selective decision problem rather than always-on adaptation.
- Uses each acquired label to evaluate all fixed candidate rules on the same input.
- Directs queries toward candidates that can still overtake the current leader.
- Stops querying when remaining labels cannot change the choice or gains don't justify cost.
- Turns an overall accuracy-losing intervention into a useful choice on selected batches.

### [Attention as Lattice Gauge Theory: Relations Interact Only Through Wilson Loops](https://arxiv.org/abs/2610.37656v1)
**Authors:** Aakash Sarkar, Ananya Mukherjee, Motoshige Sato
**Published:** 2026-10-27
**Summary:** Attention over relational graphs is uniquely determined by per-entity frame symmetry: edges interact only via Wilson-loop holonomies, yielding holonomy attention.

**What's new**
- Shows per-entity frame freedom forces edge updates of form U = Ψ(H) T_ij, with triangle scores as class functions of holonomy.
- Proves relations sharing no cycle cannot interact in the pure-gauge sector, making Wilson-loop attention the unique symmetry-permitted form.
- Unifies commuting knowledge-graph embeddings (abelian sector), AlphaFold triangle updates, Edge Transformer, and lattice QCD as special cases.
- Holonomy attention infers unobserved S4 relations at 0.88 with 20% corrupted edges, versus 0.083 cap for commutative architectures.
- Flags corrupted triangles at AUC 0.99 (commuting scores capped at 0.76) and separates clusters without labels or training.
