### [Flash-dLLM: IO-Aware KV Caching and Parallel Decoding for Fast, Memory-Efficient Diffusion LLMs](https://arxiv.org/abs/2609.26796v1)
**Authors:** Quan Nguyen-Tri, Mukul Ranjan, Zhiqiang Shen
**Published:** 2026-09-22
**Summary:** Flash-dLLM is a training-free inference acceleration framework for diffusion LLMs that uses IO-aware KV caching and parallel decoding to achieve up to 11x speedup.

**What's new**
- Identifies GPU memory I/O as dominant bottleneck in KV-cache-enabled dLLM inference.
- Introduces I/O-aware fused KV-cache kernel to reduce redundant memory movement.
- Proposes KV-cache-driven draft-and-verify decoding where dLLM acts as both drafter and verifier.
- Achieves 5.1x and 11.0x speedups over Elastic-Cache on GSM8K and HumanEval, respectively.
- Improves scalability to longer sequences and larger batch sizes while preserving generation quality.

- Self-organized cooperation patterns emerge and standardize as organization grows

### [CliffCompaction: Cost-Efficient Compaction for Long-Horizon Coding Agents](https://arxiv.org/abs/2609.26779v1)
**Authors:** Trang Nguyen, Eulrang Cho, Bingqing Chen, Tim Dettmers
**Published:** 2026-09-22
**Summary:** CliffCompaction cuts long-horizon coding agent costs up to 50% by truncating rather than rewriting context, boosting Terminal-Bench and KernelBench results.

**What's new**
- Autocompaction reduces cost up to 50% under bounded context while maintaining or improving Terminal-Bench performance.
- Keeps compacted info faithful by only truncating or dropping content, never rephrasing or rewriting it.
- Never compacts a compaction; each pass uses only original content, preventing context drift accumulation.
- Enables test-time scaling gains of over 10 points on Terminal-Bench for under two full-context run costs.
- Open-source scaffold-agnostic API-proxy implementation works with Claude Code, Codex, and other harnesses.

### [Greedy Decoding Is Not Precision-Invariant: Cross-Precision Output Divergence in LLM Inference](https://arxiv.org/abs/2609.26621v1)
**Authors:** Gaoyuan Du, Anam Nawaz Khan, Rex Zhou, Xiaoyang Liu, Deepayan Chakrabarti, Fnu Suya, Xueping Li
**Published:** 2026-09-22
**Summary:** Greedy decoding is not precision-invariant: BF16 vs FP16 yields divergent outputs, driven by top-two logit margin, with selective FP32 LM head recomputation as partial mitigation.

**What's new**
- Same model, prompt, and greedy decoding diverge in BF16 vs FP16 on identical hardware; 49-100% of prompts diverge across six models.
- A single token flip often cascades into trajectory-level divergence, not just a local difference.
- 22 layers of accumulated body error do not distinguish flipping from non-flipping steps; top-two logit margin relative to directional perturbation does.
- Five testable predictions from error-propagation analysis all matched, including that broader FP32 compute worsens agreement.
- Selective FP32 LM head recomputation when margin is low gives +22-36 pp exact agreement on A10G at <4% latency overhead for batch <=4.

### [Calibration as a First-Class Criterion in LLM Evaluation](https://arxiv.org/abs/2609.26489v1)
**Authors:** Mario Sanz-Guerrero, Katharina von der Wense
**Published:** 2026-09-22
**Summary:** Paper argues calibration should be a standard evaluation criterion for LLMs, not a niche topic, since miscalibration harms deployment and research pipelines.

**What's new**
- Calibration adoption gap: NLP research introduces models and benchmarks without checking confidence meaningfulness.
- Miscalibration harms both deployment (overconfident mistakes) and research (LLM-as-a-judge, synthetic data, active learning).
- Standard calibration metrics need only confidence scores and correctness judgments, which most benchmarks already provide.
- Open-ended generation still lacks clear definitions for these two calibration inputs.
- Calls for each NLP subfield to pair its main performance metric with a calibration score.

### [Beyond Scalar Sensitivity: Activation-Aware Mixed-Precision LLM Quantization with Cross-Layer Refinement](https://arxiv.org/abs/2609.25916v1)
**Authors:** Akihiro Yoshida, Yuma Ichikawa
**Published:** 2026-09-22
**Summary:** CASA replaces scalar sensitivity proxies with activation-aware Kronecker-factored metrics plus cross-layer search for mixed-precision LLM quantization.

**What's new**
- Proves scalar proxies distort sensitivity by up to sqrt(kappa(A)kappa(B)), ranging 10^1 to 10^13 in LLM modules.
- Stage 1 uses activation-aware Kronecker-factored Hessian metric with closed-form MCKP relaxation.
- Stage 2 applies cross-layer-aware local search using end-to-end model loss for bit-width updates.
- Outperforms scalar-proxy baselines in perplexity, especially below 3 bits per weight.
- Zero-shot gains track per-model average condition number, validating the distortion bound.
