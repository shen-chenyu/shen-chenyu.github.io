# Daily Issue (JST): 2026-10-16

## What's New Today

**AI Agents Learn to Forget, Robots Adapt, and Materials Get Generative**

Today's papers span AI agent self-improvement, efficient transformer inference, and physics-informed machine learning. A recurring theme is forgetting or compressing information to scale discovery and long-context reasoning. In materials and physics, machine-learned potentials and neural operators push simulation boundaries.

**Highlights**
- Scaling discovery requires forgetting: periodic reset of agent search state prevents anchoring and plateaus.
- Transformers can be made elastic at inference time, adapting compute to query load without retraining.
- Continuum Attention replaces discrete key-value lookup with continuous memory integration, improving likelihood.
- Humanoid control policies can be generated directly in weight space via latent diffusion.
- Machine-learned interatomic potentials reproduce defect sorption trends in 2D materials at scale.
- Neural operators with fractional derivative orders improve PDE surrogate accuracy.
- Agentic markets and multi-developer systems show emergent scaling and welfare trade-offs.

### [Continuum Attention](https://arxiv.org/abs/2610.20586v1)
**Authors:** Afshin Khadangi
**Published:** 2026-10-14
**Summary:** Continuum Attention replaces discrete key-value lookup with integration over a continuous piecewise linear memory curve, improving validation loss over softmax and focal attention.

**What's new**
- Introduces Continuum Attention (CA), a causal Transformer attention operator using continuous memory integration.
- Each query induces an exponential relevance density along a piecewise linear memory curve.
- Exact normalized attention computed in closed form from exponential moments, including half token boundaries.
- Gradients follow analytically from moments of order at most two, enabling parallel GPU implementations.
- Reduces mean validation NLL by 0.0200 and 0.0480 nats/byte vs softmax and focal attention, winning all paired comparisons.

**Summary:** CIPR, a self-supervised KL-divergence objective aligning action distributions across two equivalent interfaces, improves LLM agent robustness to interface perturbations.

**What's new**
