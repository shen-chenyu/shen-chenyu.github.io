## Featured Papers

### [ChunkAct: Action Chunking for Agentic Robotics](https://arxiv.org/abs/2610.18874v1)
**Authors:** Bingxin Xu, Wenrui Bao, Xinxin Liu, Jiawei Zhou, Yuzhang Shang, Emilio Ferrara
**Published:** 2026-10-13
**Summary:** ChunkAct adds action chunking to LLM-driven agentic robotics, cutting redundant reasoning by executing chained primitives per single LLM call.

**What's new**
- Introduces action chunking to agentic robotics, where one LLM call launches a chunk of chained primitives
- Chunks execute autonomously and return control only on failure, reserving the planner for real decisions
- Offline compilation of memory into chunks makes execution memory-free at test time
- LLM computation scales with decisions rather than primitives
- On LIBERO-Pro: +5.0 success points, 2.9x fewer LLM calls, 4.4x fewer input and 2.3x fewer output tokens

### [Tev: Scaling Long-Horizon Agentic Environments with Dense Progress Rewards](https://arxiv.org/abs/2610.18868v1)
**Authors:** Wenbo Hu, Shraman Pramanick, Krishna Kumar Singh, Nanyun Peng, Kai-Wei Chang, Yong Jae Lee
**Published:** 2026-10-13
**Summary:** Tev introduces Tev-Gym, a long-horizon agent dataset with dense progress rewards, and Tev-27B, a model trained via progress-potential reward shaping that matches top models on agentic benchmarks.

**What's new**
- Tev-Gym: first long-horizon agent training dataset with verifiable, dense, progressive rewards across 1,170 environments and 7 domains
- Latent-world-first approach builds a hidden task specification, then progressively renders it into controllable agent-facing environments
- Progress-potential reward shaping (PPRS) converts progress into dense per-step rewards, making intractable tasks trainable
- Tev-27B matches GPT-6 Astra and Claude Opus 5 at Pass@5 on ALE-CM computing and math sciences domains
- Generalizes to Terminal-Bench 3.0/4.0, surpassing GLM 5.2 and Gemini 3.7 Flash, and reaches Claude Opus 4.8 level on TB 2.1

### [Data Free Training of Diffusion Models for Lattice Field Theories](https://arxiv.org/abs/2610.18863v1)
**Authors:** Dennis Grinwald, Ankur Singha, Khaled Kahouli, Karl Jansen, Shinichi Nakajima
**Published:** 2026-10-13
**Summary:** Diffusion models for lattice field theory can be trained without target data using score identities from unnormalized densities, matching HMC-trained performance.

**What's new**
- Trains diffusion models without samples from the target distribution, avoiding the original sampling bottleneck.
- Uses target score identity with access only to the unnormalized probability density.
- Importance-weighted variants give a consistent target; unweighted variants form a self-consistent fixed-point scheme.
- Benchmarked on 2D phi^4 theory across symmetric, critical, and broken phases.
- Data-free training achieves performance comparable to training on HMC reference data.

### [SEAR: Self-Evolving Agentic Robotics](https://arxiv.org/abs/2610.18792v1)
**Authors:** Xinyi Wang, Bangzheng Li, Hanyu Wang, Lin Zhang, Andrea Yaoyun Cui, Zhenggang Tang, Shyamal Buch, Dejia Xu
**Published:** 2026-10-13
**Summary:** SEAR benchmarks self-evolving robot agents across three modes, seven LLMs, 330 simulated and five real tasks, separating genuine learning from retries.

**What's new**
- Introduces SEAR, a framework and benchmark for self-evolving agentic robotics with code-as-policy, agent-as-policy, and auto-research modes.
- Controls separate retained experience from repeated attempts, familiar tasks, privileged state, larger budgets, and luck.
- Longer sessions pay off on hard tasks; on easy tasks, re-rolling short attempts works just as well.
- Control code and shared routines transfer across tasks and simulators, but task-specific solutions do not.
- Different models evolve best in different modes, and a text-only model matches a comparable multimodal one.

### [MultiAlloc: Budget-Aware Precision Allocation for KV Cache Quantization](https://arxiv.org/abs/2610.18642v1)

**Published:** 2026-10-13
**Summary:** MultiAlloc is a profiling-guided framework that allocates a fixed KV cache memory budget between layer-wise precision and token-wise preservation for LLM inference.

**What's new**
- Frames KV cache quantization as allocating limited resources across heterogeneous precision strategies under a fixed budget
- Uses lightweight offline profiling of layer sensitivity and token importance to derive an allocation policy
- Avoids online allocation search by precomputing the memory-accuracy trade-off and applying it at inference
- Outperforms layer-wise, token-wise, and multi-granularity KV quantization baselines at matched memory budgets

### [DoubtLess: Training-Free Contrastive Decoding for Efficient Reasoning](https://arxiv.org/abs/2610.18862v1)
**Authors:** Minghao Luo, Liang Chen
**Published:** 2026-10-13
**Summary:** DoubtLess is a training-free decoding method where a small reasoning model steers a large one toward shorter chains of thought without losing accuracy.

**What's new**
- A small model reads the large model's CoT twice, prompted brief and verbose, and their logit difference steers decoding.
- Shortens Qwen3-32B CoT by 31% on seven benchmarks with unchanged accuracy, beating five inference-time baselines.
- Cuts thinking tokens per turn by 20% in a self-debugging coding agent with unchanged task performance.
- Generalizes to two other model families and stacks with training-based compression for further shortening.
- Ablations show it mainly reduces repeated checking, with savings after the correct answer first appears.

### [Exact Topological Compliance: Generating Persistence-Equivalent Graphs](https://arxiv.org/abs/2610.18856v1)
**Authors:** Mattie Ji, Indradyumna Roy, Vikas Garg
**Published:** 2026-10-13
**Summary:** Two methods generate graphs whose persistence diagrams exactly match a target, using local degree-based construction and global constraint satisfaction.

**What's new**
- First principled approach to exact topology-compliant graph generation, not just approximate.
- Local method iteratively builds degree-based PD-equivalent graphs with proven completeness.
- Local generation trades off sample diversity and feasibility, motivating global approach.
- Global method recasts generation as constraint satisfaction, solvable by CP solvers.
- Applicable to any vertex-based permutation equivariant filtration, minimal under degree filtration.

### [Two Clocks: Why Larger Rollout Batches Learn Slower but Fail on Schedule in Reinforcement Learning with Verifiable Rewards](https://arxiv.org/abs/2610.18853v1)
**Authors:** Yuante Li, Junwei Quan, Kai Qiu, Kate Zhang, Yicheng Tao
**Published:** 2026-10-13
**Summary:** Two-clock framework shows larger rollout batches in RLVR learn slower per sample and fail on schedule, with square-root LR scaling not preserving progress.

**What's new**
- Square-root LR scaling preserves first-order drift per sample but not progress due to curvature.
- Critical batch size exists beyond which sample efficiency degrades, depending on learning rate.
- Failure clock sample count is approximately invariant along the square-root rule.
- Ratio clipping delays failure but progress gap persists; widening clip trades stability for speed.
- Simple multi-step schedule: start below critical batch, switch to larger batch before failure.
