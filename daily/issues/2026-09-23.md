### [Don't mind the gap: Absolutely Continuous Edge Spectrum in a Mobility Gap](https://arxiv.org/abs/2609.25000v1)
**Authors:** Simon Becker, Mengxuan Yang
**Published:** 2026-09-21
**Summary:** Nonzero bulk topological index forces the entire mobility gap to be absolutely continuous edge spectrum in 2D lattice and magnetic Schrödinger operators.

**What's new**
- Proves edge spectrum fills the whole mobility gap, not just isolated energies.
- Links constant nonzero bulk topological index to absolutely continuous half-space spectrum.
- Bounds absolutely continuous spectral multiplicity below by |index| at almost every energy.
- Handles both 2D lattice Hamiltonians and magnetic Schrödinger operators.
- Notes Section 2.3 auxiliary-space cut construction first version was generated using ChatGPT 6.

### [Critical-State RL: Diagnosing Trainable States for Multi-Turn Tool Use](https://arxiv.org/abs/2609.24985v1)
**Authors:** Zixiang Chen, Wenting Zhao, Zhepeng Cen, Akshara Prabhakar, Jielin Qiu, Jianguo Zhang, Zhiwei Liu, Tulika Manoj Awalgaonkar, Liangwei Yang, Shelby Heinecke, Silvio Savarese, Huan Wang
**Published:** 2026-09-21
**Summary:** Critical-State RL identifies which multi-turn tool-use calls are trainable by separating action-dependent reward variation from continuation noise, then trains only at those states.

**What's new**
- Introduces Critical-State RL to diagnose trainable states in multi-turn tool use.
- Uses nested sampling to separate action-dependent reward variation from continuation noise.
- Optimizes selected states via contextual-bandit training.
- On BFCL v4, training diagnostic-selected states improves performance by ~14 points on missing-function tasks.
- Training alternative states leaves performance flat or worse.

### [Harness-Zero: Harness Distillation via Agent-as-Harness](https://arxiv.org/abs/2609.24974v1)
**Authors:** Haoran Ye, Yuxing Lu, Haonan Dong, Zhaochen Su, Guojie Song
**Published:** 2026-09-21
**Summary:** Harness-Zero distills optimized agent harnesses into model weights via agent-as-harness correction, removing the harness at deployment while improving task success.

**What's new**
- Introduces agent harness distillation: transferring harness-induced behaviors into model weights so gains survive under a fixed target harness.
- Uses agent-as-harness: a harnessing agent corrects student responses in the target action space, turning guidance into training demos.
- Agent-as-harness outperforms code-as-harness for frontier LLMs using the same evolved harness.
- Removing the specialized harness at deployment, Harness-Zero lifts macro-average task success from 23.3% to 44.3%, beating the 41.7% with harness attached.
- Recovers 82.3% of harness-induced behaviors across 28 patterns in knowledge work, tool use, and science domains.
