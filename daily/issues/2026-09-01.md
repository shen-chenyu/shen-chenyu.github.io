### [Reward-guided Fine-Tuning of One-Step Generative Models via Wasserstein Gradient Flow](https://arxiv.org/abs/2608.29647v1)
**Authors:** Hoseong Hwang, Woorim Han, Joungin Chun, Jinseong Park, Jaewoong Choi
**Published:** 2026-08-30
**Summary:** Introduces a reward-guided fine-tuning method for one-step generative models using Wasserstein Gradient Flow, requiring no reward gradients and improving reward alignment.

**What's new**
- Proposes WGF-based fine-tuning for one-step generators, enabling smooth distributional updates.
- Method avoids reward gradients, handling both differentiable and non-differentiable rewards.
- Mitigates reward hacking and mode collapse during fine-tuning.
- Demonstrates superior reward alignment on CIFAR-10 and ImageNet with diverse rewards.

### [Detect Before You Attribute: Cascade Failure Attribution for Multi-Agent Systems](https://arxiv.org/abs/2608.29646v1)
**Authors:** Jiayi Zhang, Zexin Wang, Degang Sun, Changhua Pei, Fei Sun, Gaogang Xie, Jingjing Li
**Published:** 2026-08-30
**Summary:** DUOTRACE is a plug-and-play detection filter that improves LLM-based failure attribution in multi-agent systems by first detecting anomalous executions.

**What's new**
- Introduces detect-before-attribute paradigm for failure attribution.
- Uses dual-view semantic-structural node representations for VAE-based anomaly detection.
- Employs Tree-LSTM trajectory encoder to handle hierarchical execution structures.
- Includes prefix-chain and LLM-based data augmentation to address limited failure data.
- Improves agent-level and step-level attribution accuracy by 8.7% and 7.0%.

### [Agent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents](https://arxiv.org/abs/2608.29606v1)
**Authors:** Ming Wu, Pengyuan Zhu
**Published:** 2026-08-30
**Summary:** Agent Zero Memory is a provenance-aware long-term memory system for LLM agents, using three parallel memory structures and citation-locked reading to achieve state-of-the-art accuracy.

**What's new**
- Introduces three parallel memory systems: episodic timeline, entity-event graph, and hierarchical documentary memory.
- Implements citation-locked reading: answers can only cite evidence the reader actually opened, structurally preventing fabrication.
- Uses an intent gate to skip retrieval for self-contained turns, reducing latency.
- Achieves new SOTA on LongMemEval (95.60%) and LoCoMo (93.60%), with up to 20x lower cost per query.

### [Solid and Quasi-Solid Electrolytes for Zinc Batteries: Balancing Water Activity, Ion Transport, and Interfaces](https://arxiv.org/abs/2608.29586v1)
**Authors:** Souvik Naskar, Jiaqian Qin, Eric Jianfeng Cheng
**Published:** 2026-08-30
**Summary:** This review critically examines solid and quasi-solid electrolytes for zinc batteries, highlighting the trade-off between suppressing water-related issues and maintaining ion transport, and proposes controlled-solvation hybrids as the near-term solution.

**What's new**
- Distinguishes water content from thermodynamic water activity in electrolyte classification.
- Argues that bulk ionic conductivity alone does not predict cell performance; thickness, transference, and interfaces matter.
- Identifies controlled-solvation and hybrid electrolytes as the most credible near-term path.
- Calls for transparent reporting of solvent state and validation with realistic testing conditions.

### [PINN-Phase: A physics-informed neural network for curvature-driven multiphase-field evolution](https://arxiv.org/abs/2608.29413v1)
**Authors:** Seifallah Elfetni, Peter H. Seeberger, Theodore Tyrikos-Ergas
**Published:** 2026-08-29
**Summary:** PINN-Phase is a physics-informed neural time integrator for multiphase-field evolution, enabling fast, accurate long-horizon predictions without case-specific tuning.

**What's new**
- Enforces phase bounds and unit sum at every step, ensuring physical admissibility.
- Achieves 0.94-3.71% terminal grain-label disagreement on unseen microstructures.
- Rollouts are ~5.2 min on a single GPU, reaching nearly 3x the training horizon.
- Pre-registered 64-grain model retains all reference survivors with 6.09% disagreement.
- 3D model recovers exact terminal active sets in six of six unseen microstructures.

### [Unified Gas-Kinetic Wave-Particle Method for Multiscale Simulation of Vlasov-Poisson-Fokker-Planck System](https://arxiv.org/abs/2608.29580v1)
**Authors:** Zhigang Pu, Chang Liu, Yixiao Wang, Kun Xu
**Published:** 2026-08-30
**Summary:** A unified gas-kinetic wave-particle method with Fokker-Planck collisions (UGKWP-FP) is developed for multiscale simulation of the Vlasov-Poisson-Fokker-Planck system.

**What's new**
- Extends UGKWP framework to Fokker-Planck collisions via Lenard-Bernstein operator.
- Decomposes FP operator into nonstiff drift-diffusion and stiff thermalization parts.
- Uses modified Ornstein-Uhlenbeck process for particle dynamics and BGK relaxation for thermalization.
- Adaptive wave-particle representation transitions from kinetic to continuum regimes.
- Recovers original FP dynamics in rarefied limit and hydrodynamic limit under strong collisions.

### [A Causal Model for Locating and Unlocking Sandbagging in Model Organisms](https://arxiv.org/abs/2608.29461v1)
**Authors:** Hong Kiat Tan, Linh Le, David Williams-King
**Published:** 2026-08-29
**Summary:** A causal model of sandbagging in LLMs identifies a single residual stream axis for intent, enabling layer-specific grafts to restore capabilities.

**What's new**
- Proposes a causal model where early layers write sandbagging intent onto one residual stream axis, read by a later layer.
- Single-layer reference graft restores capability in 28/33 runs across prompting, fine-tuning, and RL locks (median 96% recovery).

### [Reference-Grafting Matches Fine-Tuning at Eliciting Sandbagged Capabilities](https://arxiv.org/abs/2608.29458v1)
**Authors:** Linh Le, Hong Kiat Tan, David Williams-King
**Published:** 2026-08-29
**Summary:** Reference-grafting, which sets activations along contrast directions to honest reference values, matches fine-tuning in eliciting sandbagged capabilities without weight updates.

**What's new**
- Recovers +94-101% of honest-sandbagging gap across 11 models, matching fine-tuning.
- Requires only 2-5 paired examples to fit the contrast direction.
- Works for RL-induced sandbagging and password-locked code generation.
- Reveals sandbagging as a thresholded gate, explaining why additive steering fails.
- Direction is specific to induction method, not content, and circuit-breaking limits fixed edits.
