## Featured Papers

### [When Debate Amplifies Risk: Social-Bias Vulnerabilities in Multi-Agent Safety Deliberation](https://arxiv.org/abs/2611.04289v1)
**Authors:** Qinghua Mao, Xi Lin, Yuxin Qi, Zihao Xu, Jinze Gu, Yuliang Chen
**Published:** 2026-11-03
**Summary:** Multi-agent debate can amplify latent web safety risks via social biases, but an inference-time debiasing framework suppresses unsafe adoption to ≤2%.

**What's new**
- Introduces SafeConflict-Bias, a counterfactual protocol isolating majority sway, authority cues, and confidence asymmetry across six web risk categories.
- Shows standard multi-agent debate raises unsafe adoption from 0.0% to 100.0% and silences safe minority evidence.
- Proposes RiskTrace-Debias, an inference-time framework using evidence-first precommitment, social-metadata masking, and consistency-gated arbitration.
- Cuts worst-case unsafe adoption to ≤2.0% across architectures without over-refusal or retraining.
- Generates verifiable provenance traces to audit interpersonal manipulation in web deliberation.

### [MCP Tool Poisoning in Agentic AI Frameworks: A Cross-Framework Measurement Study](https://arxiv.org/abs/2611.03555v1)
**Authors:** Farooq Shaikh, Biagio Montaruli
**Published:** 2026-11-02
**Summary:** First cross-framework measurement of MCP tool poisoning with real execution finds 22.9% attack success across 9,720 cells, with resistance driven by model choice rather than framework defenses.

**What's new**
- Introduces mcpvenom, an open-source tool driving a 9,720-cell susceptibility matrix across 12 frameworks, 18 models, and 45 attack scenarios.
- Uses a dual oracle confirming real exfiltration via canary HTTP receipt, unlike prior benchmarks that only measure model compliance.
- Finds 22.9% overall attack success: 64.9% dispatch attacker tool calls, 23.0% contact attacker endpoints, 12.1% verifiably exfiltrate secrets.
- Resistance is model-level: nine core frameworks cluster within 23-26% (p=0.91), and no framework implements intentional defense.
- Model ASR spans 0.4% to 49.7%; a regex description scanner rejects 20 of 45 scenarios at 7.2% false-positive rate, making metadata scanning only partial.

### [SEAM: Situated Executable Associative Memory for a Co-located Community](https://arxiv.org/abs/2611.04296v1)
**Authors:** Keru Wang, Michael Xu, Ken Perlin, Nebojsa Jojic, Andrzej Banburski-Fahey
**Published:** 2026-11-03
**Summary:** SEAM is a social app prototype that builds a shared, situated associative memory for a co-located community, letting members post moments, query the memory, and program its behavior.

**What's new**
- Prototypes a community-level shared memory inspired by individual recall and stimulus response.
- Automatically relates posted fragments, distills group knowledge, and replies in a situated, associative way.
- Members can issue memories as instructions that alter system behavior, making it programmable by users.
- Deployed to 46 people for two weeks plus a 14-person workshop, with open-ended real use.
- Replies introduced members to unfamiliar people and subjects, pointing toward knowledge finding people.

### [WASP-Mem: Let Agent Organize Procedural Memory. Human Spend Effort on Diagnosis](https://arxiv.org/abs/2611.04003v1)

**What's new**

### [The Agent Board: Kanban for Machines; Durable Coordination for Agents That Outlive the Conversation](https://arxiv.org/abs/2611.04100v1)
**Authors:** Tyler Hunt, Donald Nguyen, Gurbinder Gill
**Published:** 2026-11-03
**Summary:** The Agent Board is a durable, shared kanban-style task table that lets multiple LLM agents coordinate, wait, and hand off work across conversations and vendors.

**What's new**
- Durable shared board of semi-semantic tasks: exact routing fields plus free-form prose only LLMs read.
- Agents block on tasks by ending their turn, holding no process until a matching post wakes them.
- A Board Keeper system agent acts as interrupt handler, matching events to prose waiters and spawning agents.
- Loadable coordination policy kernels give statuses and roles meaning without the board enforcing them.
- Pilots: wait cost flat in wait length vs ~165x growth for naive polling; 3.6% missed wakes, no false wakes.

### [FlagRot: Selective Rotation for Low-Bit KV Caches](https://arxiv.org/abs/2611.03992v1)
**Authors:** Kunming Shao, Xijie Huang, Jierun Chen, Jiaqi Shao, Yanli Wang, Jiangnan Yu, Qiwei Li, Wei Zhang, Kwang-Ting Cheng, Chi Ying Tsui
**Published:** 2026-11-02
**Summary:** FlagRot selectively rotates 32-channel KV cache pieces only when it reduces calibrated attention error, improving 2-bit quantization over always-rotate methods.

**What's new**
- Shows rotation doesn't always help: it can flatten spiky keys but create new peaks in flat ones.
- Stores each 32-channel piece rotated or unrotated based on smaller calibrated attention error, rotating query at read.
- Decision frequency follows quantization axis: per-head for per-channel caches, per-key for per-token caches using sign bits.
- At 2.5 bits, lowers KIVI's 12-model KL divergence from 18.7 to 12.4e-3, beating RotateKV on 9 of 12 models.
- As a vLLM plugin, gains +2.9 RULER at 128k and +0.4 to +1.9 LongBench v1 mean; also helps 4-bit INT and FP4 caches.

### [GC-MoE: Overlapping Expert-Parallel Token Dispatch with FP8/FP4 Grouped GEMM via CUDA Green Contexts](https://arxiv.org/abs/2611.04222v1)
**Authors:** Yong Li, Kan Liu, Tao Lan
**Published:** 2026-11-03
**Summary:** GC-MoE uses CUDA Green Contexts to split GPUs into communication and compute partitions, overlapping MoE token dispatch with FP8/FP4 grouped GEMM for faster decode.

**What's new**
- Splits device into small comm partition and large compute partition via CUDA Green Contexts, each with own kernel and sync domain

- 1.188x avg speedup on 8 H20 GPUs; 1.106x on 8 B300, beating Mega MoE at all 54 points; uses only 20 of 148 SMs for dispatch

### [EpiLoRA: Fusing Many LoRA Adapters into Low-Precision GEMMs for Serving and RL](https://arxiv.org/abs/2611.03899v1)
**Authors:** Hieu Tran, Hong Yu
**Published:** 2026-11-02
**Summary:** EpiLoRA fuses many LoRA adapters into low-precision GEMM epilogues, cutting per-token latency and enabling FP8-based RL training on a single GPU.

**What's new**
- Launches down-projection first, then runs low-precision GEMM as dependent kernel adding each tenant's up-projection in its epilogue.
- On Hopper GPUs, up to 24% lower time per token for single-adapter decoding than vLLM's fastest config, beating SGLang and TensorRT-LLM.
- With many tenants, adapter kernels deliver more throughput than vLLM's on most tested GPU-model pairs.
- RL trainer computes on engine's FP8 weights with no 16-bit copy, training a 27B model on one 48 GB GPU.
- Keeping activations in 16 bits removes most mismatch between data-generating and trained models.

### [Accurate representation of the continuum orbital in a Gaussian basis set: application to Auger decay rates](https://arxiv.org/abs/2611.04202v1)
**Authors:** Dibyendu Mahato, Saikat Roy, Wojciech Skomorowski
**Published:** 2026-11-03
**Summary:** A Gaussian-basis method solves the Lippmann-Schwinger equation with an auxiliary-GTO Green's function to represent multicentered, multichannel continuum orbitals and compute Auger decay rates.

**What's new**
- Represents continuum orbitals in a discrete basis of standard Gaussian-type orbitals, compatible with conventional quantum chemistry.
- Solves the Lippmann-Schwinger equation with correct boundary conditions using an analytical Green's function in an auxiliary GTO basis.
- Yields multicentered, multichannel continuum orbitals for a rigorous description of scattering states.
- Applied to Auger decay rates in Ne, H2O, CO2, and Ar, with results improving systematically as continuum quality increases.
- Shows higher-order bound-domain electron correlation is essential for accurate satellite transitions.

### [Tokenizer Myths and Where To Find Them](https://arxiv.org/abs/2611.04215v1)
**Authors:** Rylan Schaeffer, Sanmi Koyejo
**Published:** 2026-11-03
**Summary:** The paper debunks three tokenization myths, showing BPB and 'tokenizer-agnostic' metrics are biased, and proposes a tokenizer trilemma.

**What's new**
- Myth #1: BPB is not tokenizer-agnostic; untrained models show BPB prefers some tokenizers over others.
- Myth #2: Lower BPB does not mean a better model; it correlates weakly with downstream performance.
- Myth #3: 'Unigram-normalized loss' is not tokenizer-agnostic; its 0.989 BPB correlation drops to 0.057 when fixed.
- Introduces a tokenizer trilemma: no metric can score only the true distribution best, be prediction-invariant, and tie all untrained models.
- Concludes with cautions for reading tokenization literature and a conjecture for future work.

**What's new**
- Generates protein conformational ensembles at a user-specified folding fraction Q from sequence alone, without per-protein simulation.
