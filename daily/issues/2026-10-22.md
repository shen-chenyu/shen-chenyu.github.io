## Featured Papers

### [GBClaw: An agentic AI framework for atomistic grain boundary research and mechanistic discovery](https://arxiv.org/abs/2610.28629v1)
**Authors:** Yazhuo Liu, Kunqing Ding, Xiaoguo Gong, Zifeng Wang, Yichen Yang, Yifeng Che, Wen Chen, Josh Kacher, Olivier Pierron, Shigenobu Ogata, Ting Zhu
**Published:** 2026-10-20
**Summary:** GBClaw is an agentic LLM framework that automates simulation and mechanistic analysis of general grain boundaries, applied to 14 asymmetric tilt GBs in nickel.

**What's new**
- Modular LLM architecture with orchestrator, specialized agents, domain tools, simulation interfaces, and hierarchical memory
- Dynamic replanning and iterative workflow refinement link systematic simulations to targeted mechanistic analysis
- Characterized interfacial defect structures and diverse deformation modes across 14 incommensurate Ni GBs
- Found secondary GB misfit dislocations substantially alter shear strength, revealing defect-hierarchy effects on sliding resistance
- Researcher-guided follow-ups traced anomalously high shear resistance to metastable boundary structures

### [UniWALM: Unified World Action Language Model for Embodied Robot Control](https://arxiv.org/abs/2610.28626v1)
**Authors:** Rahul Sajnani, Diego Romeres, Mingyuan Zhang, Kai Gao, Carl Qi, Baichuan Huang, Srinath Sridhar, Dylan Randle, Lillian J. Ratliff, Jose Barreiros, Manikantan Nambi, Jeroen Vanbaar
**Published:** 2026-10-20
**Summary:** UniWALM unifies video, action, and language in one mixture-of-transformers backbone with per-modality diffusion heads, using generated language as memory to improve embodied manipulation.

**What's new**
- Single shared representation where each modality is both conditioning signal and supervision target
- Per-modality diffusion heads co-denoise synchronously, decoding language memory alongside action with no separate planner
- Generated language is re-consumed next step, closing a language-as-memory loop without external memory bank
- Flow Matching with Correction (FMC) teaches recovery from perturbed action trajectories at no inference cost
- Reaches 34.5% on memory-dependent RMBench without pretrained language models; real-world Find-the-Item rises 11.1% to 61.1%

### [Adaptive Multi-Token Prediction: How far should we go?](https://arxiv.org/abs/2610.28619v1)
**Authors:** Emile Anand, Mohammed Rehan Parwani, Xinyuan Cao
**Published:** 2026-10-20
**Summary:** AMTP is a lightweight, retraining-free controller that adaptively selects the multi-token prediction horizon per context using verification feedback, decoding up to 4.1x faster.

**What's new**
- Formulates MTP horizon selection as an online control problem using acceptance survival to predict draft reliability.
- Introduces AMTP, a controller that picks the horizon maximizing expected tokens per second without retraining.
- Proves prediction error translates to throughput regret and sublinear regret with online gradient descent.
- Achieves up to 4.1x faster decoding and up to 10% throughput gains over fixed windows in 8 of 10 settings.

### [Differentiable powder X-ray diffraction enables analysis of evolving structures](https://arxiv.org/abs/2610.28564v1)
**Authors:** Xiangyu Yin, Nina Andrejevic, Hemant Sharma, Ming Du, Aileen Luo, Michael Prince, Burak Guzelturk, Xiaoyi Zhang, Brian H. Toby, Mathew J. Cherukara
**Published:** 2026-10-20
**Summary:** diffPXRD is a differentiable PyTorch powder XRD engine enabling fast batched fitting of shared structural models across evolving operando diffraction series.

**What's new**
- Differentiable PXRD engine in PyTorch using automatic differentiation, so shared models can change without new derivative code.
- Batched fitting is over seven times faster than serial pattern-by-pattern fitting.
- Shared lattice model cuts lattice-parameter variability by 68.4% at 10% photon counts in an operando cathode series.
- Shared models capture Li2S precipitation/dissolution and reconstruct collective atomic displacements in Ca3Ti2O7.

**What's new**
