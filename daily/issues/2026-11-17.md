### [A Matrix with Steps: An Episodic and Procedural Memory Method for Tool-Using Agents and Robots](https://arxiv.org/abs/2611.20230v1)
**Authors:** Jürgen Paulhart, Peter Schüller
**Published:** 2026-11-15
**Summary:** Episodic and procedural memory for tool-using agents stores only externally verified outcomes, using a delta-rule matrix to find procedures and ordered step records for sequencing.

**What's new**
- Only externally confirmed outcomes (tests, tool results, people) are stored; the agent's own success claim never counts.
- Memory splits into an associative delta-rule matrix that finds applicable procedures and ordered addressable step records for what comes next.
- Self-judging robot reported 96% done but solved 35%; with external verification it solved 79%.
- In 100,000 synthetic episodes (457MB), oldest episode found first, no cross-user leakage, unverified successes never recalled.
- Lookups took 16ms on a laptop and 40ms on a server node; exact records solved every revisit at first attempt up to ~10,000 confirmed records.

### [Interface-Selective Extreme Ultraviolet Second Harmonic Generation Away from Linear Absorption Edges](https://arxiv.org/abs/2611.20198v1)
**Authors:** Bailey R. Nebgen, Shane W. Devlin, Franky Bernal, Aga Ridhova, James Bullock, Daniel R. Schacher, Jake D. Koralek, Yuya Kubota, Shigeki Owada, Toshihide Sumi, XingYu Su, Iwao Matsuda, Keith V. Lawler, Walter S. Drisdell, Michael W. Zuerch, Craig P. Schwartz
**Published:** 2026-11-15
**Summary:** XUV second harmonic generation measured below the Si L-edge reveals structured, interface-selective signals from buried Si/SiO2 interfaces in a photovoltaic heterojunction.

**What's new**
- Demonstrates XUV SHG away from linear absorption edges, where linear absorption is a featureless valence background.
- Observes strong structured XUVSHG maxima near 70 and 76 eV for 60-76 eV fundamentals in an ITO/MoO3/SiO2/Si stack.
- Layer-resolved first-principles calculations assign both peaks to the Si/SiO2 interface, distinguishing bridging Si monolayer from near-interface substrate.
- Bethe-Salpeter calculations link the signal to Si 2p excitons at 140-160 eV, connecting off-edge response to core excitations.
- Establishes off-edge XUV SHG as a route to selectively probe distinct buried interfaces in complex heterostructures.

**What's new**
- Introduces Sr3Fe2O5X2 (X = F, Cl, Br) as a layered semiconducting oxyhalide family with high-temperature antiferromagnetism.
